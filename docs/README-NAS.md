# المكتبة الشاملة — نسخة الأندرويد على NAS

نقلٌ كامل لبيانات المكتبة الشاملة (shamela.ws — قاعدة البيانات الرسمية ١٤٤٨، الإصدار ١٤٤٨٫٨ من البرنامج) إلى صيغة مفتوحة (SQLite + FTS5) مستضافة على NAS سينولوجي في المجلد `/downloads/shamela`، مع تطبيق أندرويد مستقل يقرأها ويبحث فيها دون اتصال، ويجلب المستجدات من موقع الشاملة مباشرة.

## ما في المجلد على NAS

| الملف | الوصف |
|---|---|
| `manifest.json` | ملف الوصف الذي يقرأه التطبيق (رابطه الدائم: `https://files.murabbie.org/fsdownload/FnGtHqpG9/manifest.json`) — **لا تُلغَ مشاركته** |
| `master.db.gz` | فهرس المكتبة (الأقسام ٤١، المؤلفون ٣٬١٨٨، الكتب ٨٬٥٩٣ + مواضع ملفات الكتب في الحزم) — يُنزَّل عند أول فتح (نحو ٣ م.ب) |
| `index.json` | فهرس الحزم: لكل كتاب اسم الحزمة والإزاحة والطول والحجم والبصمة وعدد الصفحات |
| `books.pack` | **ملف الكتب الموحَّد** (٨٫٩ غ.ب): كل كتاب قاعدة SQLite مضغوطة gzip مستقلة داخل هذا الملف الواحد، يُنزَّل بطلب مدى (HTTP Range) دون تنزيل الملف كله |
| `books-upd-YYYYMMDD-HHMMSS.pack` | حزم التحديث التي يُنشئها سكربت المستجدات |
| `shamela-<الإصدار>-universal.apk` | التطبيق (يعمل على كل المعالجات) — وهذا الملف الذي يُنشر للناس |
| `shamela-<الإصدار>-arm64.apk` / `-arm32.apk` | نسخ أصغر لمعالج بعينه |
| `shamela-android-project.tar.gz` | لقطة للقراءة فقط من مجلد `android/` (Kotlin/Compose) عند الـ commit المنشور، يولّدها `publish.py app` من GitHub. المصدر الكامل (المستخرج والسكربتات) في https://github.com/talibfitrah/shamela-fitrah |
| `tools/` | السكربتات: `zipfetch.py`، `make_master.py`، `publish.py`، `update_from_web.py`، `shamela_common.py`، والمستخرج `shamela-extractor-1.0.jar` |
| `publish_state.json` | حالة النشر (روابط المشاركة وبصمات الملفات) — يعتمد عليه سكربت التحديث |
| `SHA256SUMS.txt` | بصمات التحقق |

## كيف بُنيت البيانات

حزمة الشاملة الرسمية `shamela-database-1448.zip` (١٣٫٣ غ.ب) لا تحوي نصوص الكتب في ملفات SQLite الصغيرة الخاصة بكل كتاب (`book/NNN/ID.db` — فيها أرقام الصفحات والأجزاء وفهرس العناوين فقط)، بل في فهرس **Lucene 10.4** (`store/page` و`store/title`) داخل الحقول المخزَّنة (`id`، `body`، `foot`). لذلك:

1. `tools/zipfetch.py` يجلب من الحزمة الرسمية — بطلبات مدى مباشرة من `dev.shamela.ws` دون تنزيل ١٣ غ.ب — الملفات اللازمة فقط (نحو ٥٫٧ غ.ب): ملفات الحقول المخزَّنة `.fdt/.fdx/.fdm` والمقاطع المركبة `.cfs/.cfe` والقوائم الحية `.liv`، وقواعد الكتب الصغيرة، و`master.db`.
2. المستخرج `extractor/` (Java + lucene-core 10.5.1) يقرأ المقاطع مباشرة بواجهة `StoredFieldsReader` (فلا يحتاج ملفات الفهرس المعكوس الضخمة)، ويمر أولًا على حقل `id` لكل مستند حي ليبني خريطة كتاب ← مواضع صفحاته، ثم يبني لكل كتاب قاعدة SQLite:
   - `page(id, part, page, number, body, foot, services)` — النص كما هو في الشاملة (أسطر مفصولة بـ `\r`، وعناوين الفهرس داخل `<span data-type="title" id=toc-N>`)
   - `title(id, page, parent, text)` — فهرس الموضوعات شجرةً
   - `page_fts(body, foot)` و`title_fts(text)` — FTS5 بلا محتوى على النص **المطبَّع** (بلا تشكيل، توحيد الهمزات والألف المقصورة والتاء المربوطة، أرقام لاتينية) بالدالة نفسها في `Norm.java` و`ArabicText.kt` و`shamela_common.py`
   - `meta(key, value)`
   
   ثم يضغط كل قاعدة gzip ويضمها إلى حزمة `books-NN.pack` (نحو ١ غ.ب لكل حزمة) ويكتب `index.json`. عند تكرار صفحة في أكثر من مقطع يغلب المقطع الأحدث.
3. `tools/make_master.py` يبني `master.db` للتطبيق: جداول الشاملة الرسمية + `book_file` (مواضع الحزم) + `book_norm`/`author_norm` (للبحث المطبَّع في الأسماء وترتيب المضاف حديثًا).
4. `tools/publish.py` يرفع كل شيء إلى NAS بواجهة DSM، وينشئ روابط مشاركة دائمة لكل ملف، ويكتب `manifest.json`.

النتيجة: ٨٬٥٩١ كتابًا، ٧٬٦٠٤٬٨٠٧ صفحة، ٤٬٠٦٤٬٨٤٥ عنوانًا (انظر `index.json` للأرقام النهائية).

## الوصول إلى NAS (بلا حساب)

التطبيق لا يستعمل أي حساب على NAS (لا manus ولا غيره). يُنزّل كل شيء عبر **روابط المشاركة العامة** للمجلد `/downloads/shamela`. ملاحظة مهمة: طبقة nginx أمام سينولوجي تُرجِع خطأ ٤٠٤ متقطعًا على مسار `/fsdownload` حين يذهب طلب تهيئة جلسة المشاركة وطلب التنزيل إلى عاملَي DSM مختلفين؛ لذلك يُنفّذ التطبيق **طلب التهيئة (`/sharing/<id>`) وطلب التنزيل على اتصال TCP واحد** (عميل OkHttp مخصَّص ببِركة اتصال لكل عملية)، فيُصيبان العامل نفسه وتصبح النتيجة موثوقة (ثبت ٨/٨ ثم عيّنات متعددة ١٠٠٪). التنزيل يدعم المدى (Range) والاستئناف.

## التطبيق

- **أول فتح:** ينزّل فهرس المكتبة تلقائيًا ثم تظهر المكتبة كاملة (الأقسام، المؤلفون، كل الكتب، المثبَّتة، المضاف حديثًا) مع بطاقة كل كتاب (المؤلف، القسم، الطبعة، الصفحات، الحجم، روابط PDF، الطبعات الأخرى).
- **القراءة الفورية دون تنزيل:** تفتح أي كتاب فيُجلب فورًا عند الطلب (بضع مئات الكيلوبايت إلى ميغابايتات) ويُقرأ ويُبحث فيه؛ لا يلزم تنزيل مسبق. و**التنزيل للاستخدام دون اتصال** خيار داخل التطبيق.
- **التنزيل:** كتاب بكتاب (أيقونة السحابة)، أو قسم كامل، أو كل كتب مؤلف، أو المكتبة كلها؛ يعمل في خدمة خلفية بإشعار، بطلبات مدى من الحزم، مع التحقق من sha256 وفك الضغط، والاستئناف، وخيار Wi‑Fi فقط.
- **القراءة:** تقليب بالسحب، فهرس الموضوعات، الانتقال إلى جزء/صفحة، حجم الخط والتباعد والخط، التشكيل، الهوامش، المظهر (فاتح/داكن/ورقي)، علامات، تعليقات خاصة، نسخ/مشاركة الصفحة مع المرجع، حفظ آخر موضع، فتح روابط `shamela.ws/book/ID/PAGE` داخل التطبيق.
- **البحث:** في كل الكتب المثبَّتة أو قسم أو كتب مختارة أو كتاب واحد؛ كل الكلمات / أي كلمة / عبارة، البادئات، الهوامش، العناوين فقط؛ نتائج مجمَّعة بالكتاب مع مقتطفات مظلَّلة، والانتقال إلى الصفحة مع تظليل الكلمات.
- **المستجدات:** يقرأ «آخر الكتب المضافة» من shamela.ws؛ ما وصل إلى NAS يُنزَّل من الخادم، وما لم يصل بعد يُجلب من الموقع صفحةً صفحة (`ajax/pageContent` + `ajax/titlechilds`) ويُبنى له الفهرس نفسه على الهاتف. ويفحص التطبيق يوميًا `manifest.json` ليعرض تحديث التطبيق أو الفهرس.

## تحديث NAS بالمستجدات

```bash
# في أي جهاز يصل إلى NAS و shamela.ws (يلزم python3 و curl)
cd tools
python3 update_from_web.py work            # يجلب الكتب الجديدة من قائمة المستجدات
python3 update_from_web.py work --ids 30250,30251   # كتب بأرقامها
```
يحتاج المجلد `work/` إلى `master-official.db` (نسخة `master.db` الرسمية من الحزمة). يُنشئ حزمة `books-upd-YYYYMMDD-HHMMSS.pack`، ويحدّث `index.json` و`master.db.gz` و`manifest.json` على NAS، فتظهر الكتب الجديدة في التطبيق بعد «تحديث الفهرس».

## إعادة البناء من حزمة رسمية جديدة

```bash
python3 tools/zipfetch.py data 'store/page/.*\.(fdt|fdx|fdm|cfs|cfe|liv)$' 'store/title/' 'database/book/' 'database/(master|cover)\.db'
java -Xmx3g -jar extractor/target/shamela-extractor-1.0.jar data out --packSize 20000000000   # ملف واحد books.pack
python3 tools/make_master.py data/master.db out/index.json out/master.db
python3 tools/publish.py data out out/master.db --version 1449-1
```
(عدّل `URL` في `zipfetch.py` إلى رابط الحزمة الجديدة، وأعد توليد `ents.pkl` بقراءة الدليل المركزي كما في التعليق أعلى الملف.)

## بناء التطبيق

```bash
cd android && gradle assembleRelease   # يلزم keystore.properties (انظر keystore.properties.example)
python3 ../tools/publish.py app app/build/outputs/apk/release 2 1.1.0 --notes "ما الجديد"
```
